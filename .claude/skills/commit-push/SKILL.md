# コミットして push する

## 手順

1. `git status` で変更を確認する。機密情報(パスワード・APIキー・個人情報)が含まれていないか確認し、含まれていたらコミットしない。
2. 関連する変更ごとにまとめて `git add` する。
3. 日本語で、何をなぜ変えたかが分かるメッセージでコミットする。

```bash
git commit -m "案件: セミナー企画書の初版を作成" -m "Co-Authored-By: Claude <noreply@anthropic.com>"
```

   接頭辞の目安: `組織:`(メンバー・ルール) / `スキル:` / `案件:` / `経営:`(vision・決定) / `記録:`(communications) / `設定:`

4. 通常は push しない。セッションの終了時(と次の開始時)にフックがまとめて push する。オーナーに頼まれたときだけ、その場で `git push` する(upstream 未設定なら `git push -u origin HEAD`)。
5. push に失敗したら `git pull --rebase` してから再度 push する。衝突したら勝手に解決せずオーナーに報告する。

## 注意

- `push --force`、履歴の書き換え、ブランチの削除はオーナーの指示なしに行わない。
