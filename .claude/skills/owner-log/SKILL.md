# オーナーとのやり取りを記録する

## 手順

1. 今日の日付で `communications/YYYY-MM-DD.md` を開く。なければ `# YYYY-MM-DD オーナーとのやり取り` の見出しで作る。
2. 話題ごとに次の形式で追記する(同じ話題の続きなら既存の節を更新する)。

```markdown
## 話題のタイトル

- **オーナーの指示**: (オーナーの言葉を要約。重要な言い回しはそのまま)
- **CEO の対応**: (やったこと・提案したこと・反論したこと)
- **成果物**: (ファイルへのリンク)
- **決定事項**: (決まったこと。なければ「なし」)
- **宿題**:
  - オーナー: (オーナーにお願いすること)
  - CEO: (CEO が次にやること)
```

3. 決定事項があれば `management/decisions.md` の表にも1行追記する。
4. 宿題があれば `management/tasks.md` に反映する。

## 注意

- パスワード・口座番号などの機密情報は書かない。
- 会話の逐語録ではなく、後から読んで経緯が分かる要約にする。
