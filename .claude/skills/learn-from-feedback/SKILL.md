# 指摘から学ぶ

間違ったら直す、を繰り返すことで「間違えない CEO」に育つ。

## 手順

1. 何を指摘されたのか、なぜダメだったのかを一文で整理する。分からなければオーナーに確認する。
2. 目の前の成果物を直す。
3. `organization/rules/lessons.md` の末尾に追記する。

```markdown
## YYYY-MM-DD: 一行タイトル
- 何が起きたか: (自分が何をして、オーナーに何を指摘されたか)
- 今後のルール: (次から必ずこうする、という具体的な行動)
```

4. その場限りでなく役割全体に関わる教訓なら、該当メンバーの `profile.md` や `.claude/agents/<id>.md` にも反映する。
5. 「ルールに追記しました」とオーナーに一言報告する。

## 注意

- 「気をつけます」のような曖昧なルールにしない。行動で書く。
- 既存のルールと重複・矛盾したら、既存のものを書き換えて1つにまとめる。
