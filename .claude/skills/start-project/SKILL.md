# 案件を立ち上げる

## 手順

1. 案件名を英小文字とハイフンで決める(例: `ai-seminar-2026-11`)。
2. `projects/<案件名>/` に次を作る。
   - `brief.md`(下のテンプレート)
   - `deliverables/`(成果物置き場。最初は `.gitkeep` だけ)
   - `notes.md`(調査メモ・経過)
3. `brief.md` を埋める。分からない項目は推測で埋めず「要確認」と書き、オーナーに確認する。
4. `management/tasks.md` に案件のタスクを追加する。
5. 担当が CEO 以外のメンバーなら、そのメンバー(サブエージェント)に brief.md を渡して指示する。

## brief.md テンプレート

```markdown
# 案件名

- **目的**: なぜやるのか(会社の目標とのつながり)
- **ゴール**: 何が実現したら完了か
- **成功基準**: 数値で測れる基準(根拠も)
- **期限**:
- **責任者**: (1人)
- **予算・制約**:
- **オーナーにお願いすること**: (オーナーにしかできないことだけ)

## 進め方
1.
2.

## リスク・懸念
-
```
