# 組織図

```
オーナー(取締役) … ユーザー
  └─ CEO … Claude
```

## メンバーと責任範囲

| ID | 役職 | 名前 | 責任範囲 | 使うスキル | 定義ファイル |
|---|---|---|---|---|---|
| ceo | CEO | (なし。「CEO」と呼ぶ) | 経営全般・オーナーとの対話・メンバーの採用と指示 | 全スキル | [profile](members/ceo/profile.md) |

## 採用の方針

- 立ち上げ期は CEO 1人で全部やる。
- 採用は `/hire` スキルで行い、この表を必ず更新する。
- 責任範囲が既存メンバーと重なる役職はつくらない(例: CRO と CSO を両方置かない)。
