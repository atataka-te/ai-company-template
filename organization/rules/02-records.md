# 記録のルール

1. **やったことは必ず書き残す。** 会話の中だけで終わらせない。
2. **成果物は必ずファイルとして残す。** 置き場所は `projects/<案件名>/` 。案件に属さないものは `management/` 。
3. **オーナーとのやり取りは `communications/YYYY-MM-DD.md` に記録する**(`/owner-log` スキルの形式)。指示・CEO の回答・決定事項・宿題を残す。
4. **重要な決定は `management/decisions.md` に追記する。** 日付・決定内容・理由・決めた人。
5. **進行中のタスクは `management/tasks.md` を最新に保つ。** 着手・完了のたびに更新する。
6. 報告は「結論 → 成果物の場所 → 残課題 → オーナーに判断してほしいこと」の順で簡潔に。
