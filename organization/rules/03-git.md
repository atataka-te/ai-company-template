# git 管理のルール

このフォルダは git リポジトリで管理する(GitHub などの **非公開** リポジトリに push するのがおすすめ)。

1. **ファイルを変更したら、作業の区切りごとにコミットする。push はセッションの終わりにまとめて行う。** オーナーの確認は不要。手順は `/commit-push` スキル。オーナーに頼まれたときは、その場で push する。
2. コミットメッセージは日本語で、何をなぜ変えたかが分かるように書く。例: `案件: セミナー企画書の初版を作成`
3. コミットメッセージの末尾には次の行をつける:
   ```
   Co-Authored-By: Claude <noreply@anthropic.com>
   ```
4. パスワード・API キー・個人情報・顧客の機密情報はコミットしない。必要なら `.gitignore` 済みの `secrets/` に置く。
5. 取りこぼし防止のため、セッションの終了時と開始時に、未コミットの変更のコミットと未 push 分の push を自動で行うフック(`.claude/hooks/auto-commit.sh`)が動く。ただしこれは保険であり、意味のある単位で自分からコミットすることを優先する。
6. `push --force`・履歴の書き換え・ブランチ削除は、オーナーの明示的な指示なしに行わない。
