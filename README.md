# AI 会社テンプレート(Claude Code)

Claude Code を「アシスタント」ではなく **自分の会社の AI CEO** として動かすためのフォルダ一式です。
作者の会社で 2026-10 から実際に毎日動かしている仕組みから、事業の中身と個人の情報を抜いて作りました。

## 何ができるか

- **会話をまたいで仕事が続く**: 会話を始めると、フックが「ビジョン・タスク・直近のやり取りと宿題」を CEO に自動で渡す。毎回説明し直さなくてよい。
- **記録が勝手に残る**: やり取りは `communications/`、決定は `decisions.md`、タスクは `tasks.md` に CEO が書く。変更は自動でコミットされる。
- **任せる線引きがはっきりしている**: お金・社外への送信・方針の変更はオーナーの承認が必要、それ以外は CEO が決めて進める(`organization/rules/04-authority.md`)。
- **指摘されたことを繰り返さない**: 指摘を受けると、CEO が教訓をルールとして `lessons.md` に足す。
- **会社が自分を見直す**: 月1回の全社レビューで、ルール・スキル・フォルダを点検して改善を提案する。
- **無人の定期実行**(Windows): 決まった時刻にスキルを動かし、結果を次の会話で CEO が報告する。

## 必要なもの

- Claude Code(Claude の有料プラン)
- git(Windows なら Git for Windows。フックは bash で動く)
- 定期実行を使う場合: Windows のタスクスケジューラ(Mac・Linux では cron などに置き換えが必要。未対応)

## 始め方

1. このフォルダを好きな場所に置き、git の管理にする。
   ```bash
   git init
   git add -A
   git commit -m "会社を設立"
   ```
   (任意)GitHub などに **非公開** のリポジトリを作り、`git remote add origin <URL>` しておくと、会話の終わりに自動で push される。
2. このフォルダで Claude Code を開く。最初の会話で、たとえば次のように話しかける。
   > 会社を始めたい。事業内容と当面の目標を一緒に決めて。
3. CEO が `management/vision.md` を埋める案を出すので、決める。あとは仕事を振るだけ。

## フォルダ

`CLAUDE.md` の「フォルダ構成」を見てください。最初に手を入れるとよい所:

| ファイル | 何を書くか |
|---|---|
| `management/vision.md` | 事業内容・目標(CEO と相談して決める) |
| `organization/rules/04-authority.md` | CEO に任せる範囲。自分に合わせて広げたり狭めたりする |
| `organization/rules/lessons.md` | はじめから3つ入っている教訓。合わなければ消す |

## 注意

- 無人の定期実行や自動 push は、あなたの PC と Claude の利用枠を使います。最初は手動で動かし、慣れてから登録してください。
- 個人情報・パスワード・API キーはこのフォルダにコミットしないでください(`secrets/` は git の対象外にしてあります)。
- 動作は Windows 11 で確かめています。Mac・Linux は試していません。質問・要望への返答はしていないので、自由に書き換えて使ってください。
- CEO の判断は間違えることがあります。お金や社外に関わる行動は、必ず自分で確かめてから承認してください。
